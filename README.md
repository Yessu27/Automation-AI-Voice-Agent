# Real Estate Outbound Voice AI Agent 🏡🤖

An autonomous, humanlike Outbound Voice AI solution built to qualify real estate leads and schedule property viewings in Santarém without human intervention.

### 🛠️ Tech Stack & Architecture
* **Voice & Intelligence:** Retell AI (natural conversation, prompt engineering & dedicated phone line).
* **Knowledge Base:** RAG / PDF (accurate, zero-hallucination property catalog queries).
* **Automation & APIs:** n8n (data extraction via HTTP Requests & dynamic JSON payloads).
* **CRM & Scheduling:** Google Sheets & Cal.com (real-time booking & contact management).

### 🚀 Key Impact
* 100% automated lead qualification & follow-up calls.
* Instant calendar booking during live conversations.
